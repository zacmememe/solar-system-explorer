## 用户补充的参考优先

用户最新截图`codex-clipboard-0a43a021-a8e8-478b-bf7b-178c5d4c4325.png`展示的是早期地球HUD：左边独立“模拟时间 / 50×”，右边“地球 / 6,371km”，中间为低扁椭圆的空间关系图。这比笼统的“SpaceX风格”更准确。本轮所有最终方案均以此为共同布局，不再沿用最初草稿中“中央放时间”的方向。

旧版气质的关键是两个大读数在左右形成平衡，中间保持大面积透明空间；小标题、主数字、单位和次要入口分层，边缘无需一排方框按钮。参考图没有明显强烈的侧边倾斜，座舱空间感主要来自位置图的透视、读数配重和留白。因此新倾角只做温和增强，并提供开关直接比较。

HUD15把时间、暂停、落区与资料聚在右边，中央最大宽度从780降至560px；即使按钮都可点击，也没有保住此前的构图。此次选型要比较整体重心，不再只看控件是否装得下。

## 最终三方向

| 方向 | 左侧 / 中央 / 右侧 | 形态与取舍 |
| --- | --- | --- |
| A 经典弧面（推荐） | 时间 / 空间关系或阶段弧 / 天体名称与阶段读数 | 无框、约7°轻透视；最接近用户指定的早期版本。右侧不堆主要操作。 |
| B 内收双翼 | 同上，主要操作仍在中央下沿 | 左右各一块薄白透明面，约18°透视＋1.5°轻倾；座舱感最强，但界面存在感稍高。 |
| C 全宽浅弧 | 同上，中央图形横向展开 | 无框、约11°轻透视；更像投影在宽阔前窗上，横向张力更大，扫视距离也更长。 |

共同阶段规则：观星右侧显示天体名称与平均半径；下降右侧改为站点与离地高度，中央为阶段弧；地面右侧为站点与视线方位，中央为方向带。时间一直留在左侧，直接箭头调节、独立暂停。必要操作放在中央图下沿，不恢复悬在星球上的落区面板，不加第二个“位置”入口。地形/资料说明仍按需展开。

这里只比较视觉语言。正式接入需确认平均半径是否作为默认观星主读数、超长站名折行/缩略、收起按钮、键盘焦点、临时下降1×提示与宽度断点；图与读数必须消费实际HUD快照，不能照抄示例点位、样稿27.4km或字母阶段。太阳/无着陆天体不能出现落区按钮；HOLD/升空/转场要复用已验证状态语义。倾角不能作用于世界相机，也不要跟随鼠标自动晃动。

## 交付与操作

可切A/B/C、观星/下降/地面；数字旁箭头可调，暂停、悬停/继续、返回、详情均为交互示例。可开关倾角、沉浸预览，Escape退出。键盘1/2/3切方案，O/D/G切阶段。页面下方展开历史参考，可看到用户指定截图与HUD15的布局；不同机位/天体不能作为画质对照。

背景复用原HUD方案的三张干净实机图，来自历史构建`index-VtXa3VT5.js`。尤其地面仍有当时的地平线断片，不代表目前产品，也不是本轮重验地形。顶部是统一简化占位，仅用于判断下方HUD视觉分量。图形、半径与高度均为样稿示例，页面没有连接引擎。正式接入前用当前产品重新取景验证。

样稿内容上沿约为底部142px，包括渐变；B可见玻璃高124px，其余无整块边框。这里没有宣称已达到产品98px高度或44px触控验收；选型后优先压缩间距、保持主视野，不能直接把缩放HTML当响应式实现。
