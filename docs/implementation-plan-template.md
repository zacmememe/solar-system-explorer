# 执行计划：主题

- 状态：待讨论 / 已确认 / 执行中 / 已完成
- 基线 commit：
- 审查覆盖文件：
- 目标与用户可见结果：
- 范围边界：

## 问题和源码证据

触发条件、实际行为、期望行为、相关文件/函数、已验证的原因。尚需实测的假设单列。

## 推荐方案与取舍

说明机制、涉及文件、已有接口和需要新增的接口。

## 按批次执行

每一批写明目标、修改范围、实现步骤和完成条件。发现基线不同或方案前提不成立时，报告具体差异再调整。

## 验收与回归

分别列出自动化测试、真实浏览器交互、画面检查。测试记录使用通过 / 失败 / 未运行，并写实际执行命令。

## 回退

写明可回退的提交或具体文件，不用丢弃整个工作区的方式回退。

## 执行回报

实际改动、测试结果、画面证据、偏差与遗留问题、完成 commit。
