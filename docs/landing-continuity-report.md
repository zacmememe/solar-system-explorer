# 下降中止与换落区的连续视角

任务 F-LANDING-CONTINUITY-03。用户实玩报告：中途返回仍继续下降后跳太空；换落区脱离星球后跳预设机位。base `e38620d522ecfdee8b1b0a28ad0ea6dd9a286a03`，产品候选 `aa8d9d4a2a3c7cc66a5b7dc2d58f7c7de5b08881`，分支 `codex/restore-observation-experience`。Codex根会话唯一作者，子代理仅做只读反例与复核。

## 根因与修改

1. 原返轨高度固定50km。正常UI火星约11217km处中止，随后降到49.98km再飞回远处。新轨迹捕获当前实际相机的经纬和基准面高度，目标始终高于起点；低空返回同侧局部高空，姿态随升空渐变到俯看天体。途中拖动保留用户视线，末端不额外飞往默认整球构图。是虚拟观察导览，不模拟火箭动力学。
2. 原ASCENDING完成先清空轨迹，再按旧状态调用applyLandingFrame，造成一帧目标站点+50km跳位。现在保留终端轨迹完成最后一帧，CameraController直接接手观察，不再另起flyTo。升空使用实际H−当地高程，避免重复叠加下降阶段的地形混合偏移。
3. 原准备降落隐式选择未来白昼。正常UI耶泽罗换盖尔时，模拟时间由约56.007h跳到380.007h，天体和天空都已跳动。现在降落保持当前时刻；白昼调整移到时间二级菜单的显式按钮，保留用户主动选择白昼的能力。
4. 同天体绕区走保高度的短大圆弧，必要时提高到安全净空；方向相差大于12°时，降落准备先绕到站区上空再衔接下降。背面落区的“前往落区”仍是显式绕行入口。复用同一NavigationScene避障，规划与实际渲染使用同一弧线函数。顺带修复exact导航用旧天体中心求终点、跨经度缝绕整圈，以及focusRegion沿用旧天体半径三个数值反例。
5. 准备/绕行的临时1x覆盖有完整取消和恢复；用户手动改速优先。被忽略的地表滚轮不再撤销导引，避免复用陈旧yaw/pitch突然转头。取消准备、停止转场、拖动和新目标抢占分别处理，取消后不会自动重新开始。
6. 第一轮实机复核又发现：升空途中转头后进入自由观察，near按自由支点距离计算，切掉一块月球。最终候选以目标天体实际球面净空限制near，补了可在旧版失败的近裁剪断言。该修复不代表已验证所有第三天体和山峰的碰撞。

未改变地形资产、光照曝光、天体尺寸、相机控制权或依赖。新增按钮在二级时间菜单，默认底栏高度不增加。
