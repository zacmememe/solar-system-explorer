## 默认只留一条观察仪表

大屏左侧放目标与阶段，中间留当前最必要的读数/着陆选择，右侧放主要动作。默认不展开轨道图、完整高度尺、坐标、升降率、半径、来源与设置。白色文字、细线和透明渐变沿用原方向，视觉重心留给场景。

| 场景 | 常驻 | 按需展开 |
|---|---|---|
| 观星 | 天体、落点选择/降落入口 | “位置”看系统关系；“资料”看科普 |
| 切星 | 起点→目标、细进度、停止转场 | 观测设置 |
| 下降/HOLD/返程 | 实际机位离地高度、导览细进度、当前可用动作 | “详情”看完整高度尺/速率/位置与来源 |
| 地表 | 实际视向方位、仰俯角、返程；月面保留仰望地球 | 眼高、完整指南针、重设地平线与地点说明 |

时间设置移入“···”；大屏保留天体时间暂停按钮，手机任务条收起该按钮时仍能从菜单暂停。天体时间和导览悬停语义保持分离。菜单关闭/Escape、收起/恢复、观测→时间二级入口保留焦点；“位置”菜单开始下降/转场时自动关闭。阶段自动关闭仅在焦点原本处于面板内时迁移，不抢画布/顶部导航焦点。

实测1920×1080、2560×1440和1440×900：条高86px，包含上方渐变98px。390×844和844×390任务条约111px，含渐变123px；竖屏返轨后的落点选择会换行，约164px/含渐变176px。手机兼容保留，但真实触屏/GPU未验证。

## 盖尔：恢复被抽稀掉的地形

源DEM为2m采样，原显示网格以8×12m抽样，坡地被大三角面拉平，实际可见地面和源DEM相机眼高不一致。仅盖尔落点周围加512×512m静态2m核心，外围保持原粗格：先移除完整粗单元，再以四条共边界连接带拼接，不叠加第二层面，也不动态切LOD。

`LocalTerrainRefinement.ts`构建单一索引面；`RenderedTerrain.ts`按核心/连接带/外围读取实际上传的Float32三角形。石块消费该显示采样，连接带未命中不回退到已移除粗面。源DEM、影像字节、UV、外窗边界、相机高程和书签语义保持原样；不是新增测量或影像清晰度升级。无效核心/超出窗口返回原粗网格，不留下孔洞。

三角形457084→583678（+27.7%），新增66049顶点，净几何缓冲约3.63MB。构建会复制数组，首次准备的主线程成本仍需长期关注；没有宣称零性能代价。

离线真实Gale datum=3396190m、半径2夹具：径向射线净空1.321687→1.652785m。浏览器首批实际展示比例、同机位同模拟时刻：1.216807→1.710231m，逼近相机名义1.7m，未移动相机。数值差别来自展示尺度/Float32与实际姿态，离线夹具不代替实机。共享采样按源参数重心计算，和严格径向射线也不是完全同一点；离线两点相差约2.27cm，不混称。

首批A/B仅替换地形几何，保留候选石块位置，四对都断言相机position/quaternion和时间完全相同；旧网格对照中的石块悬浮不能当作旧产品原状，因旧产品会按旧面重新放置石块。地面大折面的因果对照不受这一限制。

首批单浏览器1920×1080、各2秒：细网格前测平均11.90ms/P95 20.80ms，粗网格11.38ms/14.30ms，恢复细网格12.24ms/20.40ms。补证批同顺序为12.62/20.70、13.56/21.20、12.70/20.90ms，细粗优劣并不稳定，不能据此宣称精确性能开销。仅RAF墙钟采样，非GPU计时或性能保证；截图与资源加载会扰动结果。
