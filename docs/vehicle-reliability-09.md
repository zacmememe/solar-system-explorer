# F-VEHICLE-RELIABILITY-09：载具加载与退出收口

作者：Codex 当前会话；base `9f37d19d80c66ef59977bf74183571345fef8757`，分支 `codex/restore-observation-experience`。本轮用户授权继续系统优化，子代理仅只读审计。

## 范围与不变量

本轮只修现有机库/主场景的失败与迟到请求；不接入新载具、不改相机/时间/下降语义。生产待视觉切片仍 2/2。

- GLB 或必需纹理失败即失败，不用程序简模冒充成功；可从机库重试。
- 每个消费者独立作废自己的请求；切换、关闭、开始下降、销毁后迟到模型只释放，不挂回场景。
- 待加载选择属于内部请求，HUD/书签/成功提示只呈现已安装模型；书签可在空间到达途中预载，模型到达不另行控制相机。
- 程序纹理缓存只保留CPU source，每个模型取得独立Texture wrapper；实例内去重释放，不能释放另一个消费者仍使用的纹理。
- 先正常 UI 注入故障复现，再单测请求反例；最后生产构建验证失败/重试、延迟关闭/重开、快切、主场景失败及健康 ISS/Hubble。
