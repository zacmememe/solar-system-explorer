## 玩家能感受到的变化

普通换星会检查相机与沿途天体的相对运动，必要时绕行。旧版正常 UI 中，火卫一→火卫二穿到火星中心距离 0.10R，木星→木卫一为 0.54R，土卫六→土卫二穿到土星 0.58R。最终相同路线各为 1.45R、2.54R、2.53R；R 是该帧母行星显示表面半径，不把几何比例称为真实公里距离。

所有转场入口先读取屏幕上实际 position/quaternion，再开始新动画，包括从地表去全景/书签、快速改目标与拖动取消。普通构图的朝向沿起止四元数平滑旋转，避免绕行时追逐临时支点急转。显式天空目标、书签及地理精确目标保留原意图；没有添加空闲回正。

卫星普通导航根据母子真实相对位置取景。横屏把母星放在侧后方，竖屏放到上方留白；近卫星的大母星可以超出屏幕，但应保留可辨球缘。没有移动、放大天体或自动打开暗部补光。高速时间下母星继续正常运动，默认构图不等于持续锁镜头。

土星本体补齐色调映射/色彩输出链；环影改为分支外采样和按像素覆盖平滑边缘。巨行星本体细分从 48×36 提高至 128×96，改善近看球缘。未改变真实影像来源、环尺寸或世界深度切片。

## 实现中的关键边界

`NavigationPath` 使用连续线段相对运动扫掠、变化半径、中点曲率估计和局部自适应细分；小球长线反例用最近点局部向量计算，避免大数抵消。近地 1.7m/10m 起飞不能因整段曲率余量误拒。绕行弧可以提前/延后发生，避免参考系切换时旧卫星很早扫过机位而迫使镜头远飞。此为 UI 范围内的保守数值规划，不声称任意外部轨迹的形式化碰撞证明。

预测与实际显示共用 `calculateCelestialPresentation`，涵盖位置、半径、策略过渡、当前倍率与暂停；倍率/时刻/参考系/视口变化时重新接续规划。短飞同步完成展示过渡，书签先准备参考系和时刻后规划。不可行路线显示原因并撤销本次展示切换，不退回穿模直线。
