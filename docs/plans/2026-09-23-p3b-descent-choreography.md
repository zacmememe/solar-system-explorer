# P3b 降落编排设计（zcode 草案 2026-09-23，供 Pro 定向审）

目标体验（用户原话归纳）：飞到目标星球附近 → 视野里星球越来越大 → 平滑落地；"面向星球"到"地表视角"的切换要有顺畅过渡机制；放大过程中贴图不能越来越糊。

## 现状诊断（为什么"奇怪"）

1. 入口语义：降落按钮在"选中月球"即出现，相机可在任意位置一键开始（起点=当前机位对月面投射，可远达 400km、方位随机）。
2. 姿态跳变：startLunarLanding 后相机立刻 SNAP 到 SURFACE_LOOK 俯视姿态——从用户当前视角到下降视角无过渡（录像第 1 秒即此）。
3. LOD 断档：全球 2k 纹理的像元约 1.2km——表面充满视野时（<300km 高度）始终糊；DTM 只有 6km，中间无层。

## 设计：四相连续编排

**Phase 0 · 入场（飞向月球）**：点击降落 = 执行一次"飞向月球"的相机飞行（1.5–3s，沿用现有 flyTo），星球从画面中的小圆盘放大到充满视野。到达近月轨道（~200km）后自动衔接 Phase A。降落按钮仍可在"选中月球"时显示，但点击后的第一段就是这段飞行——用户感知即"先飞过去再降落"。
（备选：按钮只在相机距月 <N km 时出现。倾向前者：少一次状态判断，体验更顺。）

**Phase A · 星球充满视野（200km→50km）**：相机注视月球中心（planet-centered），星球充满画面持续放大。此段用轨道视角而非地表视角。

**Phase B · 转向（关键过渡，用户问的"什么时候切"）**：切换时机用**几何判据而非固定高度表**——当星球角半径 ≥ 相机半视场角（即星球边缘到达画面边界、再盯着星球中心已无意义）时开始，把注视点从"星球中心"平滑混向"飞行路径前方地平线"，混合因子 = 星球角半径/半视场的连续函数（clamped 0..1）。效果：随星球胀满画面，视线自然从俯视抬向地平线，无感知跳变。50km 高度附近完成转向，接现有主下降曲线（T1 的全局进度导引已是连续的）。

**Phase C · 地表下降（50km→1.7m）**：现有实现（HOLD/视线保留/触地）不动。

## LOD 换层判据（用户问的"贴图变糊"）

按**屏幕空间像元尺寸**换层：层像元角尺寸 > 1 屏幕像素即淡入下一层（连续 20–30% 高度带交叉淡化，不做硬切）。按 1440px/50°FOV 粗算换层高度：

| 层 | 像元尺度 | 像元达 1 屏素的高度 | 状态 |
|---|---|---|---|
| 全球 2k 纹理 | ~1.2 km/px | ~3 km（即 300km 以下全程偏糊） | 已有 |
| LROC WAC 全球彩色镶嵌 | ~100 m/px | ~290 km | 待获取（PDS 公开，多 GB，整文件+裁窗管线现成） |
| LOLA DEM（几何） | ~237 m/px | 配合 WAC 层淡入 | P3-T5 已登记 |
| NAC DTM+正射 | 5 m | ~15 km | 已有（T2 无缝衔接） |

即：300km→15km 由 WAC 彩色+LOLA 几何承担"放大变清晰"，15km 以下 DTM 接管。数据量：WAC 全球取 64 或 128ppd 裁出区域窗（几十 MB 入库）。

## 实现风险与流程

- 相机编排放 CameraController（唯一写入者）新命令 `descentApproach`（planet-centered 注视+角尺寸混合），SolarEngine 编排四相；LandingController 只管 Phase B 以后的位移。触及相机权属/下降语义 = H 风险，按流程走设计审（本文档）+ 实现 + 独立复核。
- 分两步交付：P3b-1 相机编排（Phase 0/A/B，无新数据）；P3b-2 数据层（WAC 彩色+LOLA 几何，即 P3-T5 扩展）。

## 请 Pro 重点判断的三个问题

1. Phase B 用"星球角半径/半视场"作混合因子是否正确判据？有无更好的连续变体（如基于地平线俯角）？
2. Phase 0 用 flyTo 复用（1.5–3s 快速飞行）还是独立更长的"接近巡航"（8–15s，更有旅程感）？体验取舍。
3. WAC 全球镶嵌选 64ppd（约 1GB 源）还是 128ppd（约 4GB 源、区域裁窗后同量级入库）？
