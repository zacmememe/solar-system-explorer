## 阿波罗构型与样机边界（本次确认）

产品名称使用“阿波罗赴月组合体”，作为六款中的一款；新实现建议独立 ID `apollo-csm-lm`，不把旧 `apollo-lm` 书签悄悄解释成组合体。采用从运载火箭分离、转位对接并取出 LM 后的组合状态；CM 锥顶与 LM 顶部对接，CM 底部连接 SM，SM 后部保留主发动机喷管。真实构型参考 [NASA Apollo 11 任务记录](https://www.nasa.gov/history/apollo-11-mission-overview/) 与 [NASA 对接构型资料](https://ntrs.nasa.gov/api/citations/19690022248/downloads/19690022248.pdf)。

- 包含 CM、SM 和完整 LM（上升/下降两级），不把推进舱直接接在四脚登月舱底下。LM 本身也有推进系统；用户选择的“大喷口飞船”以服务舱主发动机和对接组合呈现。
- 不包含土星五号、S-IVB、发射逃逸塔或未分离整流罩；腿架状态、天线和隔热膜按最终选定的同一历史任务时刻核对，不拼接不同阶段的造型。
- 重点验收：三舱相对比例、对接轴线/接口、服务舱表面分区、主喷管内外轮廓、姿控喷口、LM 支腿/梯子及隔热膜。慢速转看后面与侧面也应合理。
- 默认无持续尾焰；当前伴飞是展示，不虚构正在持续点火的推力或真实赴月航迹。没有舱内模型就不制造“真实驾驶舱”。
- 本轮范围是静态装配好的单一载具，未增加对接操作、分离动画或独立登月任务；下降/地面禁用载具的既有规则继续有效。
- 现有 NASA LM 只可作为部件基础；CSM 的可靠来源、许可和实际细节仍须补齐。NASA Apollo Soyuz 是另一合体，不能直接冒称阿波罗登月任务构型。若复用其 CSM，需单独验证结构拆分、对接适配和任务差异。
- 先给完整组合体的三个方向及实际伴飞占屏样张；加载缺件/错误时不能降级显示 LM 半成品并称整体成功。做不到合理精细则停用该版本。

## 选择后怎样保证“做不好就砍”

1. **先做一款复杂样机 + 一款低风险样机**：建议航天飞机 D 与卡西尼。保持未接入生产的审美比较，给正面、背面、近看、最终伴飞小尺寸四类证据。航天飞机若无法通过，先关闭该席位，不让其拖住全部载具。
2. **按部件判断，不靠一张漂亮角度**：正常/掠射/逆光下，金属、隔热膜、太阳翼与玻璃应能区分；查看背面、接缝、法线、透明件和薄面。单纯增加粗糙度噪声不能替代真实结构。修到有限局部调整仍不能过关就退回，不无休止从零重建。
3. **检查最终看见的尺寸**：以当前 ISS 的右下方前景占屏为基准，逐款定合法朝向和视觉大小；细杆可离开主体中心但必须完整，不让太阳翼/天线挡住星球主体或 HUD。不统一放大所有飞船。
4. **工程准入后再开放入口**：资产来源/署名/哈希/轴向/米制尺度记录完备；失效不偷偷替换成粗糙程序模型；快速换载具和迟到加载不能回灌旧选择；反复开关机库后释放资源。按需下载，一次只活跃展示当前载具。
5. **产品语义不变**：只在稳定太空观察时选择与显示。准备/绕行/下降/HOLD/地面/升空仍不可用；探测器与望远镜不称“载人登船”，使用外部伴飞或仪器方向观察。没有真实舱内资产就不造驾驶舱。自由伴飞须标为展示，不暗示 ISS 真能飞到土星、或历史探测器此刻真在当前星球旁。
6. **通过结论分开**：源模型可载入、作者看图接受、正常 UI 行为/性能、独立审查、用户体验接受各自记录。当前待视觉生产切片已 2/2；选型与隔离样机可继续，生产准入仍按现有工作流，不凭选中名单自动越过审查。

建议的试做边界是每款一次结构/材质整理、一轮定向修正。若仍有关键外观缺陷，先砍掉并说明具体原因；需要全新建模或购买素材时另列具体选项给用户，不扩大成无底洞。

## 接入前发现的工程问题（尚未修改）

- `VehicleAssetRegistry.ts:256–263` 精选当前为 Hubble + ISS，全部为 7 项，默认选 ISS；不是物理删除到只剩一个。`HangarModal.tsx:610` 历史项登船入口未按 approved 禁用。新目录应真正反映准入，旧 ID 兼容与新可选列表分离。
- `VehicleLoader.ts:87–88` 的 metricScale 与 `SolarEngine.ts:3472–3473` 展示归一化写同一根节点 scale，新资产非 1 单位时可能失真。须将 metricRoot 与 presentationRoot 隔离；本轮不改，后续单独测试非 1 比例反例。
- 当前 ISS 构建包围盒约 10.65×5.4×6.25 原单位，目录标 109m；机库网格不能声称已真实 1:1。保留现外观，真实标尺与展示尺寸分别校准。
- Loader 强制 DoubleSide、失败回退程序模型；Viewer 热点仍取旧固定坐标。新资产须按实际薄面/玻璃选择策略，热点跟随居中、轴向、米制变换，不能照搬。
