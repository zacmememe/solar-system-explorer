## 结果与语义

左侧是时间大数字、减速/加速箭头、独立暂停，下面是观测选项与收起仪表。中央恢复舒展的关系图或阶段弧，降落/悬停/返回等主要操作在图下沿；落区选择仍在这里。右侧只有对象、阶段、主读数及说明入口，不再堆积时间与主要操作。

左右采用约 7° 的轻微内收透视，银白细线、透明背景，无厚边框。窄屏取消透视并分两行，保留实际至少 44px 高的点击区域。大倍率缩小数字字号，防止 86,400× 撑开左仪表。桌面高度目标按用户选定的 A 原型（含渐变不超过 142px），不是继续沿用 HUD15 的 110px。阶段切换维持侧边读数区域高度。

| 阶段 | 右侧主读数 | 中央 |
| --- | --- | --- |
| 观星 | 当前天体平均半径 | 空间关系示意，落区选择与操作 |
| 全景 / 自由环顾 | 全景 / 环顾，无残留天体半径 | 空间关系示意 |
| 转场 / 同天体绕行 | 当前转场段百分比，不冒充整体任务进度 | 来源、目标和阶段弧 |
| 准备 | 准备中，不显示规划器默认高度 | 准备状态与取消 |
| 下降 / 悬停 / 升空 | 实际观察机位离地高度 | 任务阶段弧与当下操作 |
| 地面 | 实际视线方位及方位名称，359.8° 显示 0° 北 | 方向弧、仰望地球或返回 |

`primaryReading.ts` 只读取同一发布帧；无可用读数时显示占位。全景说明面板也不显示此前选择天体的资料。详细仪表和北向透镜保留，未重新增加重复的“位置”菜单。
