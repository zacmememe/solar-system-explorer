## D. M3：数据正确与窗口限制

| 编号 | 操作 | 通过标准 |
|---|---|---|
| DATA-01 | 遍历 17 个目的地 | 名称、父天体、纹理与来源一一对应，无拼写重复主键 |
| DATA-02 | 检查半径、轨道距离、当前距离 | 单位/平均或瞬时口径明确，未混用距太阳与距父天体 |
| DATA-03 | 对照选定日期的独立星历数据 | 原点、参考系、单位、时间尺度正确，残差与模型能力相符 |
| DATA-04 | 随机取插值中点，与直接查询对照 | 保存误差统计；超出自定容差则缩小采样步长并重测 |
| DATA-05 | 拖时间到数据窗口之外 | 明确阻止或提示进入近似模式，不能无声外推 |
| DATA-06 | 故意传入 NaN、非法日期或未知天体 | 校验拒绝，无不可恢复黑屏 |
| DATA-07 | 检查构建期 JPL 请求日志 | 串行、缓存、合理 User-Agent、退避；游玩时无外部星历请求 |

工程应定义残差报告而不是伪造统一精度承诺。位置、姿态、外观来自不同模型时分别说明；本项目不以航天器导航或精密食变预测为验收范围。

## F. M5：性能、失败场景与恢复

| 编号 | 操作 | 通过标准 |
|---|---|---|
| PERF-01 | 固定桌面场景记录 60 秒帧时间 | 报告 p50/p95 与卡顿次数，不只平均 fps；标明硬件和档位 |
| PERF-02 | 两轮各 50 次相同目标切换 | 缓存预热后对象数量有界；第二轮结束不持续增长，无失控内存泄漏 |
| PERF-03 | 连续探索 30 分钟 | 无未处理异常、黑屏或持续性能衰减 |
| NET-01 | 让某目标高精图加载失败 | 低清保留或明确错误，能重试，控制仍可用 |
| TAB-01 | 后台停留 5 分钟再返回 | 不累计为失控高速位移；目标/相机保持；暂停原因符合产品定义 |
| GPU-01 | 模拟 WebGL context lost/restored | 有恢复提示/路径；恢复不丢存档与选择；未支持时明确提示而非假成功 |
| DEPLOY-01 | 从静态部署 URL 首次打开 | 路径/缓存/Content-Type 正确；深链接刷新可用 |
| OFF-01 | 已准备离线包后断开外网 | 声明离线可用的内容确实可用；没下载的内容明确标记 |
| BACKUP-01 | 空目录 + 备份恢复构建 | 原始/生产资产、lockfile、代码、数据齐全，可启动且书签可导入 |

GPU 内存没有一个跨浏览器都可靠的简单读数。以理论纹理预算、renderer 对象统计和实际稳定性共同判断。自动化无头浏览器可以测逻辑和截图，不代替真实显卡性能。

## G. 风险排序和处理顺序

P0：相机竞争、资源晚到改变目标、未知数据被标成真实、错误文件当纹理、无备份。任何一项未解决都不进入扩大内容。

P1：比例域混用、环透明排序、GPU 泄漏、移动触控冲突、星历时间/参考系错误。通过独立复现与有限测试场景处理。

P2：高质量大气、多分辨率 DEM、粒子羽流、飞船驾驶、WebGPU 迁移。没有基础数据与性能依据时延期。

一次代码提交建议只对应一项修复或一个可验收子功能；将问题、根因和回归用例留下，不保存巨量无用聊天转录作为项目记忆。
