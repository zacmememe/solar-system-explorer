# 太阳系漫游重建：研究与开发交接包

研究日期：2026-09-20。本文档用于规划和交接，不是已经实现或通过测试的游戏。

## 从这里开始

先读 `01-REBUILD-PLAN.zh-CN.md`，再把下面的启动指令交给本地 AI。`AGENTS.md` 是开发约束，`02-ASSETS.zh-CN.md` 是贴图来源和加工要求，`03-ACCEPTANCE.zh-CN.md` 是验收清单。`sources.json` 是来源索引；`asset-candidates.json` 是候选资产目录，**不是可直接发布的生产资产清单**。

本包不包含原项目代码、游戏程序或第三方贴图文件。用户上传的家庭视频也没有被放入交接包。原项目只依据本次提供的截图、视频画面和口述分析，未恢复其代码、完整文档、贴图出处或轨道算法。

已完成：公开来源页面核实、部分原图预览检查、技术方案和开发任务拆解。
未完成：在用户电脑下载并审核全部资产、检查显卡能力、运行游戏、GPU 性能测试、全部素材逐件发布授权审查。候选文件的 SHA-256 留空，不伪造文件下载或验收记录。

## 给本地 AI 的启动指令

你要帮助我重建一个给孩子和家长一起玩的太阳系漫游网页。它的核心是真实观测来源的星球/卫星贴图、让人感到空间尺度的镜头、稳定自由的观察控制，以及简单的探索乐趣。不是问答考试软件，也不是无限宇宙或专业航天模拟器。

请先阅读本包的 README、开发方案、AGENTS、资产说明和验收清单。不要一上来实现整份方案。

第一轮仅执行 M0：

1. 检查当前目录是否有已有工程、未提交修改和 Git 仓库；不要删除或覆盖。记录操作系统、Node/npm、浏览器以及浏览器可取得的 WebGL2 能力。无法取得的显卡信息写“待确认”，不猜测。
2. 采用 Vite + TypeScript + Three.js，React 仅负责界面。先核实当前稳定依赖的兼容性，固定版本并提交 lockfile。首版使用 WebGLRenderer；不同时维护 WebGPU 路线。
3. 创建一个能启动的最小页面，以及资产校验脚本、来源清单、测试框架。不要把几十个源文件的空架构当进展。只创建当下需要的模块。
4. 优先下载并核验地球和月球的低分辨率贴图。用真实图像解码检查格式、尺寸、来源、处理方式和 SHA-256；不能把 HTTP 200、文件名或网页缩略图当作验收。
5. 下载失败要保留明确错误和重试入口，不用随机噪声、AI 生成纹理或其他星球贴图替代。
6. 完成本地启动、基础类型检查和最小测试；输出启动命令、实际执行结果、可见截图、剩余风险。未运行的测试必须标注“未运行”。

M0 通过后，下一轮只做 M1 地球—月球完整体验：真实贴图、点击选择、明确的“飞往这里”、可打断飞行、自由旋转/缩放、暂停时间、不自动重置镜头。先让我实际试玩，再进入土星系统。

修改相机、缩放和资源加载时，每次只处理一个问题。第二个 AI 可以审查代码和科学口径，不要与主 AI 同时改同一组文件。每个可运行阶段单独提交，测试通过后再扩大范围。

## 本包的使用边界

规划中的帧率、内存、加载时间和工时是初始目标或估算，不是实测承诺。公开网站可用不代表每张原图已具备完整生产条件。正式公开发布时，必须检查每件资产的署名、许可与第三方权利；任何商业化范围变更都重新审查。
